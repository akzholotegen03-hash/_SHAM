# SHAM — интернет дүкені

Электроника сататын интернет-дүкеннің курстық жұмысы (БКЕ 24.31, 2026).

## Мүмкіндіктер
- Профиль ашу (аты, тегі, телефон)
- Тауарлар каталогы: іздеу, санат бойынша сүзу, баға бойынша сұрыптау
- Себет: тауар қосу/өшіру, санын өзгерту, жалпы сома
- Тапсырысты рәсімдеу және email растау коды
- Тапсырыстар тарихы
- Қазақша / орысша тіл, жарық / қараңғы тақырып
- Деректер браузерде (`localStorage`) сақталады

## Технологиялар
HTML, CSS, JavaScript (кітапханасыз).

## Қалай ашу керек
`index.html` файлын браузерде ашыңыз. Онлайн нұсқа GitHub Pages арқылы жұмыс істейді.

## Ескерту
GitHub Pages-те сервер жоқ, сондықтан email растау коды демо-режимде көрсетіледі.
